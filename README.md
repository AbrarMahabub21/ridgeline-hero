# Ridgeline Hero

A hero section for a sample landing page ("Ridgeline Web Co", websites for tradies). The background is a 3D terrain drawn with raw WebGL2 and my own shaders, with no 3D library.

## What it does

- Builds a grid of points and triangles in JavaScript and sends it to the GPU
- Vertex and fragment shaders (GLSL) shape and colour the terrain
- Moves the terrain so it never sits behind the text, on desktop and mobile layouts

## Stack

JavaScript, WebGL2, GLSL, CSS and Vite.

## Run it locally

```
npm install
npm run dev
```
